Archetype is developed in the open on GitHub, under the [`archetype-pal`](https://github.com/archetype-pal) organisation, by and for the people who use it: researchers, editorial teams, libraries and museums, and the developers who support them.

## Getting help

| You need… | Go to |
| --- | --- |
| To use the platform for research | [For researchers](/researchers/) |
| To run Archetype or change its code | [For contributors](/contributors/), then [Troubleshooting](/contributors/troubleshooting/) |
| To use the data from another tool | [The API](/contributors/api/) and [Export, reuse & cite](/researchers/interoperability/) |
| To report a bug or suggest a feature | An issue on [the frontend](https://github.com/archetype-pal/frontend/issues) (the site and backoffice) or [the backend](https://github.com/archetype-pal/backend/issues) (the API and data) |

If you are not sure which repository a problem belongs to, use the frontend.

## Contact

To discuss funding, a partnership, or running Archetype for a collection, open an issue on [this site's repository](https://github.com/archetype-pal/archetype-pal.github.io/issues). Funders may want to read [For funders](/funders/) first.

## Taking part

Code, documentation, transcriptions, corrections and feedback from real editorial work are all welcome. [For contributors](/contributors/) explains how changes are made and reviewed.

We ask everyone taking part to be respectful and collaborative, and to assume good faith.

## Licence

Archetype is developed in the open, and the team is currently choosing which open-source licence to adopt. Until one is published in the repositories, check with the project before redistributing.
